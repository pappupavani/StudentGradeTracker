# StudentGradeTracker
A robust Java-based Student Grade Tracking System designed to manage student records, calculate total and average marks, assign grades, and generate comprehensive performance reports, including highest and lowest scores.

## Features
- Enter multiple student details
- Store student name and roll number
- Enter student marks
- Calculate total marks
- Calculate average marks
- Automatically assign grades
- Display highest and lowest marks
- Generate student summary report

## Technologies Used
- Java
- VS Code
- GitHub

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Compile the program:
   javac -d out src/*.java
4. Run the program:
   java -cp out Main

## Project Output
The system displays:
- Student details
- Marks
- Grades
- Total marks
- Average marks
- Highest marks
- Lowest marks
